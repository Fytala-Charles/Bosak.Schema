# Bounded direct decimal enumeration

24 November 2026; batch slice 7, base 6113f77b464e6f9fe62e235c7211c0e5176b02a2. Exact immutable XSD 1.1 REC20120405 and XDM REC20170321 sources and affected sections are in ADOPTION.json before code. The existing signed Core 1.81.17 normalization implementation is reviewed separately in CORE-REPRESENTATION-REVIEW.json; it is not a new normative source or a Core change.

Admit enumeration on direct xs:decimal simple restrictions through the opt-in scalar/original-node facades, at all existing named/anonymous element and attribute sites and date-independent scalar roots/terminals. Existing simple-content extensions may use such a named decimal base while retaining distinct governing and atomic components. The legacy NativeDecimalSession grammar remains unchanged and refuses decimal enumeration. No user-defined decimal base chains or complex restrictions over enumerated content are adopted in this slice; explicitly refuse that latter route until its inherited facet-value contract is qualified, so membership is never silently lost or bound validity guessed.

Every enumeration declaration must be a valid bounded decimal literal for the primitive base. Collapse XML whitespace before the existing exact decimal parser. Missing/empty/invalid decimal members are Invalid schemas, including exponent/NaN/infinity/non-ASCII digit forms. Capacity excess remains Unsupported/RepresentationCapacity. At most 16 source enumeration entries are accepted, counting duplicates before deduplication; existing 256-character numeric lexical, pre-normalization digit and scale limits apply. Caller string-text capacity is not substituted for numeric limits. A facet's original raw source also remains bounded by 256 UTF-16 characters. Fixed attributes, decimal patterns/assertions and unknown facet grammar remain Unsupported.

Membership uses the normalized exact coefficient/scale value pair from the unchanged Core representation, with arbitrary-precision integer coefficients under explicit capacities. Lexical signs, leading/trailing zeroes, dot placements and signed zero do not create distinct decimal values. Do not use System.Decimal, floating point, formatted strings or a replacement enumeration literal as the value. Preserve original instance XML and the original normalized exact decimal typed value. Public equality/hash APIs are unchanged.

Enumeration combines conjunctively with local range/totalDigits/fractionDigits facets without validating base-valid sibling enumeration declarations against sibling constraints. An empty intersection is a valid schema with Invalid instances. Preserve all existing non-enumeration facet grammar, capacities and refusal classifications. The REC totalDigits definition constrains both coefficient magnitude and normalized scale; do not change it to an informal significant-digit count.

All existing authority, provenance, component identity, cancellation, disposal, recovery and no-successful-facts-on-failure rules remain.
