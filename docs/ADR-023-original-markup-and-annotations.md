# ADR023: original markup and bounded annotations

26 November 2026. Accepted for the owner-authorized next batch, subject to qualification and reviewed passing Git delivery gates.

Reuse the existing original-node adapter for comments and processing instructions. Ignore those nodes for admitted content/value checks while retaining their kind, order, parent, export, owner guard and absence of fabricated schema facts. Empty/nil still forbid text/element children. Preserve legacy decimal-only refusal boundaries.

Validate bounded schema annotation wrappers/placement, then omit them from compiler-owned parsed trees before descendant scans and closed assembly. Never traverse appinfo/documentation payloads as declarations. Count original source budgets before normalization; retain16wrapper/source capacity and explicit metadata/PSVI exclusions. Public APIs and signed Core1.86.0 remain unchanged; MinVer minimum advances to0.15. No publication or full XSD/C45 acceptance.
