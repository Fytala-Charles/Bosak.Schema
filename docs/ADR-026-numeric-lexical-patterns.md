# ADR026: bounded numeric lexical patterns

Accepted for development0.18,26November2026.

Adopt the exact REC revisions and sections recorded before implementation in [ADOPTION](numeric-patterns/ADOPTION.json). Carry immutable numeric lexical pattern plans separately from exact value facets. Validate primitive spelling/value/capacity, then match collapsed original text before publishing facts. Same-step alternatives and decimal inherited conjunctions share schema and assessment work budgets.

Enable d/Nd escapes only for numeric plans whose validated lexical alphabet is ASCII. Keep every nonnumeric call on the existing parser mode. Do not test canonical numeric rendering as a substitute for original lexical spelling. Refuse new value-space bounds/enumerations over patterned bases and numeric complex restriction paths with patterns until separately adopted. Preserve original XML, actual types, owner lifetime, legacy grammar and public API/Core pin. See [guide](numeric-patterns/GUIDE.md) and [qualification](numeric-patterns/QUALIFICATION.json).
