# ADR053: Original anonymous binary and QName bases

Status: qualified source candidate, 28 November 2026.

Admit actual compiled interchange NativeType bases through the original unnamed direct base route. Reuse the existing interchange facet compiler on original source elements, skipping only the exact inline child. Preserve exact octets, binary lengths, QName namespace context and expanded-name equality, fixed/facet/pattern ancestry, exclusions and limits without aliases or source clones. [Scope and qualification](anonymous-interchange-bases/README.md). API and Core pin unchanged.
