# Anonymous dateTime and time restriction bases

Both owned native facades admit a simple-type restriction whose one leading inline simpleType compiles to xs:dateTime or xs:time. The compiler retains that actual unnamed NativeType as the direct DerivationBase and compiles original facet elements, skipping only the exact inline base object. No alias dictionary key, synthetic QName, declaration, global anonymous entry, source clone or namespace mutation is created. References to one named outer type share its original base; independently defined source bases remain distinct. Named forward/final checks retain source authority.

Existing exact calendar semantics remain: fractional seconds, component normalization, enumeration value equality, zoned-versus-absent timezone distinction, partial-order bounds, fixed facets, explicitTimezone, collapse whitespace and lexical pattern ancestry. Same-step pattern alternatives and inherited intersections remain. Fixed calendar bounds compare exact values, so timezone-equivalent lexical forms may repeat a fixed endpoint. Bounds over patterned ancestors stay Unsupported. Assertions and other excluded syntax retain the existing profile classifications. This adds no primitive equality, ordering, lexical or normalization semantics.

Shared inline source sites remain 16 and depth remains 4. Existing year interval -long.MaxValue through long.MaxValue, lexical256, raw seconds digit/scale, string, regex, schema, atom/value and lifetime limits remain. Seconds digit/scale limits are checked before trailing-zero normalization. dateTimeStamp and other Gregorian/duration/interchange/URI/text/complex anonymous bases remain outside this batch. Broader derivation and instance-type override rules remain separate.

Complete assessment precedes facts. Atomic scalar actual-type evidence remains its governing scalar component; exact calendar transport does not substitute another type component. Original declarations, ownership, nil, original XML, recovery, cancellation, export, detached values and expiry retain their contracts. Original lexical forms stay available for patterns/export while component values use existing normalization, including signed zero years and end-of-day forms.

For example, an enumeration of 2000-01-02T12:00:00.1Z admits the equal value 2000-01-02T14:00:00.100+02:00. The detached carrier retains the latter's original offset and exact normalized fractional second. Its unzoned spelling remains distinct. A fixed minInclusive endpoint can be repeated with an equal timezone-offset spelling, while a different value is rejected.
