# ADR056: Bounded named-integer restriction chains

Status: qualified source candidate, 28 November 2026.

Admit actual named integer bases through existing ordinary and numeric-pattern routes, preserving original BaseName, direct base objects and original integer facet sources. Reuse existing exact inherited facets and retain patterned-ancestor/value-facet exclusions, final/dependency checks and capacities. Decimal pattern route unchanged. [Scope and qualification](named-integer-bases/README.md). No API/Core pin or publication change.
