## Behavior and implementation

The two opt-in mixed facades resolve the exact expanded xsi:type request from the
owning instance element's namespace scope. A compiled closed registry provides
actual native components; an immutable schema-owned graph records parsed direct
restriction bases, integer-to-decimal ancestry and complex simple-content bases.
No shared NativeType is mutated by assessment. The graph and registry are built
before the compiled schema is published.

Original declaration D and its declared T are retained. Separate effective G drives
selected facets, native annotations, guarded facts and atomic declared/governing
provenance. Unchanged complex simple content retains distinct atomic C. No-request
identities, element/attribute paths, original assessment origin, ownership and
lifetime remain intact. The processed request attribute contributes no fabricated
application scalar or QName PSVI fact. Export retains lexical XML; reassessment
resolves its type in a fresh owned episode.

Same-component and primitive-to-existing-direct-restriction selections in the same
string/decimal/integer family are admitted. Illegal weakening/siblings, absent,
unbound or malformed names are Invalid. Known excluded built-ins and legitimate
family/complex representation changes return Unsupported/ValueType. The parsed
raw QName has an independent256UTF-16 ceiling before XML whitespace collapse.
NativeDecimalSession retains refusal. No import/acquisition, inheritance grammar,
block/final/abstract, nil, list/union, new scalar family or arbitrary XPath is added.
Schema definitions with excluded constructs are still refused eagerly.
