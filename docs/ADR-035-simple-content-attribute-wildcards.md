# ADR035: Strict attribute wildcards on simple-content extensions

Status: qualified source candidate, 27 November 2026.

Retain one strict wildcard plan after existing attribute uses in the existing noninteger simple-content compiler path. Reuse global attribute assessment without changing the original complex governing type or actual scalar content type. Keep integer/assertion/restriction and wider inheritance routes separate. [Adoption and qualification](simple-content-wildcards/README.md). Public API and Core pin are unchanged.
