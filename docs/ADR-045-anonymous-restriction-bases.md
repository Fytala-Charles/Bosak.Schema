# ADR045: Original unnamed compound bases

Status: qualified source candidate,27November2026.

Compile actual inline list/union bases and link their original objects directly, preserving inherited facets and item/member authority without synthetic names. Skip only the exact inline child when compiling facets, keeping original namespace scope. Share the16 inline source-site budget and depth4 limit; preserve atomic/complex and broader profile exclusions. [Adoption and qualification](anonymous-restriction-bases/README.md). API/Core pin unchanged.
