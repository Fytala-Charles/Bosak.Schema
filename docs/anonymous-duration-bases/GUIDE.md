# Anonymous duration restriction bases

Both owned native facades admit a simple-type restriction whose one leading inline simpleType compiles to duration, yearMonthDuration or dayTimeDuration. Dispatch uses the actual NativeType object and retains it as the original unnamed direct DerivationBase. The existing duration compiler processes original facet elements, skipping only the exact inline base object. No alias, synthetic QName, declaration, global anonymous entry, source clone or namespace mutation is created. References share one base; independent definitions remain distinct. Named forward/final checks retain source authority.

Existing duration grammar and exact BigInteger month / exact-decimal second components remain. P1Y equals P12M and PT1M equals PT60S, while the original collapsed lexical form is retained. General duration ordering retains the four-reference-date partial order: P1M versus P30D is indeterminate. Such a bound rejects the instance; incomparable local endpoints remain Unsupported. Distinct component pairs with coincident reference projections, such as P400Y versus P146097D, retain the existing conservative Unsupported guard. No TimeSpan conversion or fixed month-to-day conversion is introduced.

Enumeration, bounds, fixed values, whitespace collapse and lexical pattern ancestry retain their rules. Same-step pattern alternatives and inherited intersections remain. Enumeration and bounds over patterned ancestors stay Unsupported. Equal exclusive endpoints compile a legal empty value space. yearMonthDuration rejects day/time fields, and dayTimeDuration rejects year/month fields even when zero. Existing ambiguous fractional spellings, fixed/inapplicable syntax and numeric-budget classifications remain. No primitive equality, ordering or lexical semantics are changed.

Public detached values preserve DurationValue (collapsed original lexical form), DurationMonths and DurationSeconds, together with the existing family tag and governing/actual type evidence. Native XDM payloads keep their existing Duration kind, original lexical value and schema type name. Complete assessment precedes facts. Original declarations, nil, XML, cancellation, foreign ownership, recovery, export, detached values and expiry retain their contracts.

Shared inline source sites remain 16 and depth remains 4. Existing supplied and aggregate digit/scale budgets, lexical256, string/regex/schema/atom/value and lifetime limits remain. Interchange, URI, other text and complex anonymous bases, wider derivation/instance overrides and assertions require separate adoption. The source candidate is unpublished; these contracts do not establish complete XSD 1.1, PSVI or public Core acceptance.
