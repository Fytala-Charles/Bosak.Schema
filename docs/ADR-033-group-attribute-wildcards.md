# ADR033: Strict attribute wildcards on all/choice roots

Status: qualified source candidate,26November2026.

Reuse immutable compiled wildcard metadata on bounded root compositors and named aliases; preserve original group validators, physical child order and element-only no-typed-value semantics. Retain old internal sequence accessor and nested-container exclusions. [Adoption and qualification](group-wildcards/README.md). API and Core pin unchanged.
