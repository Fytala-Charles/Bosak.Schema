# Anonymous Gregorian restriction bases

Both owned native facades admit a simple-type restriction whose one leading inline simpleType compiles to gYear, gYearMonth, gMonth, gMonthDay or gDay. Dispatch uses the actual NativeType object and retains it as the original unnamed direct DerivationBase. The existing Gregorian compiler processes original facet elements, skipping only the exact inline base object. No alias, synthetic QName, declaration, global anonymous entry, source clone or namespace mutation is created. References share one base; independent definitions remain distinct. Named forward/final checks retain source authority.

Existing Gregorian lexical/component mapping and reference-component arithmetic remain. Equality is timezone-aware and distinguishes absent from explicit timezone. Ordering remains partial where timezones are absent. Enumeration, bound/fixed/timezone/whitespace and lexical pattern ancestry retain their existing rules. Same-step pattern alternatives and inherited intersections remain. Enumeration and bounds over patterned ancestors stay Unsupported; incomparable local endpoints stay Unsupported. Existing fixed/inapplicable syntax classifications remain. No primitive equality, ordering, lexical or reference-component semantics are changed.

Public detached values preserve their Gregorian family, collapsed original lexical form, supplied components and optional timezone. Missing public components remain absent even when equality/ordering uses REC reference components internally. Native atomic payloads retain their existing Gregorian schema type tag and original governing/actual type evidence. For example, an anonymous gDay enumeration of ---15+14:00 accepts ---14-10:00 as an equal value while retaining the latter's original day and offset. gMonthDay equality uses the existing leap-year reference rules without adding a public year component.

Shared inline source sites remain 16 and depth remains 4. Existing year interval -long.MaxValue through long.MaxValue where applicable, lexical256, string/regex/schema/atom/value and lifetime limits remain. Duration, interchange, URI, other text and complex anonymous bases, wider derivation/instance overrides and assertions require separate adoption. Complete assessment precedes facts. Original declarations, nil, XML, cancellation, foreign ownership, recovery, export, detached values and expiry retain their contracts.
