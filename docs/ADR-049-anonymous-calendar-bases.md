# ADR049: Original anonymous dateTime and time bases

Status: qualified source candidate, 27 November 2026.

Dispatch on actual compiled xs:dateTime or xs:time NativeType objects. Preserve direct original unnamed base links and compile original facet elements, skipping only the exact inline base. Reuse existing exact calendar value/facet ancestry and limits without aliases, source clones or broader type-family admission. [Scope and qualification](anonymous-calendar-bases/README.md). API and Core pin unchanged.
