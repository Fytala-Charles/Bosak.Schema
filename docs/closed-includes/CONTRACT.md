# Closed same-namespace schema inclusion

25 November 2026; batch slice14. Adopt the exact verified slice13 main revision and immutable Structures REC20120405 section4.2.3 plus3.17/3.3/3.4/3.7 and XDM31 REC20170321 before implementation.

Add two overloads to the existing owned facades: Create(string rootDocumentUri, IReadOnlyDictionary<string,string> schemaDocuments, NativeSchemaSessionOptions options, CancellationToken cancellationToken=default). Retain every existing API row and type. This is an additive public API change, with exact expected reflection rows and explicit review. The supplied catalog is copied before compilation; it owns schema text, never resolution callbacks or host resources. Root and catalog identifiers must be absolute URIs with no fragment. Relative schemaLocation resolves against the containing document's identifier. Only catalog matches are used; network, file access and DTD/entity resolution never occur. Missing catalog references return Unsupported. Do not infer that a URI naming a local/remote resource grants access to it.

Catalog cap8 documents, each32KiB UTF8, total64KiB, identifier1024UTF16; aggregate effective schema retains current32KiB and component/profile capacities. Inventory keys canonicalize through Uri.AbsoluteUri, duplicate canonical identities and invalid identifiers are bounded Unsupported configuration refusals, not XSD validity judgments. Null API inputs throw ArgumentNullException; cancellation remains caught by caller convention. Unused catalog entries are capacity-checked but are not schema components and are not semantically adopted.

Compile the transitive include closure with URI-based document deduplication, including legal include cycles/diamonds. Root declarations precede included declarations in deterministic depth-first include order. Included targetNamespace must equal the root namespace; mismatching nonempty targetNamespace is Invalid. Chameleon conversion from absent targetNamespace to a nonempty target namespace is explicitly Unsupported. No-namespace into no-namespace includes are admitted. Each included document must have identical effective elementFormDefault, attributeFormDefault and xpathDefaultNamespace to the root; varying per-source contexts remain Unsupported until a native multi-document component compiler is designed. Each source root obeys existing schema attribute boundaries. Include requires schemaLocation, no metadata/annotation children beyond the profile. Imports/redefine/override remain Unsupported.

Assemble a private compilation input once per source component, retaining each source's actual namespace bindings on that component before removing it from its private source root. Never use namespace-stripping, textual prefix substitution, ambient resolvers, per-use authoritative copies or user-owned XML mutation. Source URI provenance is not added to current public facts and must not be claimed. Existing canonical component identity, group/local/global type identity, original instance nodes, typed values, namespaces, bounds, failure/cancellation/ownership/lifetime remain. Existing single-string Create still refuses include; no implicit resolver is introduced.

Qualify same/no-namespace/relative/forward/diamond/cyclic/global/group/type/attribute cases, alias bindings, differing form-context/chameleon/import refusal, mismatch validity, missing documents, source/catalog/aggregate/identifier ceilings, duplicate keys, caller-catalog mutation, cancellation, API shape, original facts and no invalid partial values. Source/package/native/examples/corpus/retained/Core signatures/supplemental/docs and additive API review precede authorized Git delivery/green merge/main verification. No registry publication or Core/C45/full XSD/PSVI claim.
