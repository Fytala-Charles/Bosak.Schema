# ADR051: Original anonymous Gregorian bases

Status: qualified source candidate, 27 November 2026.

Admit actual compiled Gregorian NativeType bases through the original unnamed direct base route. Reuse the existing Gregorian facet compiler on original source elements, skipping only the exact inline child. Preserve component/value/reference arithmetic, timezone equality/partial order, fixed/facet/pattern ancestry, exclusions and limits without aliases or source clones. [Scope and qualification](anonymous-gregorian-bases/README.md). API and Core pin unchanged.
