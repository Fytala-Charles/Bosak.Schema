# Closed attributes after a bounded default-group opt-out

Both owned native facades can establish Invalid for ordinary undeclared attributes on a bounded complex owner that explicitly opts out of a schema default group, declares no attribute uses and has no wildcard. The supported owners are existing empty and finite element-only sequence types, including named roots, aliases, local/nested owners and global references. The ignored group does not supply declarations or an implicit wildcard. A matching global attribute declaration alone does not make an ordinary attribute legal.

A private plan policy is set from the original source complexType and schema context and retained in both root-alias copies. The existing declared-use/wildcard assessment path rejects ordinary extras. Original source type/declaration objects, actual instance selection and canonical references retain authority; no aliases, synthetic nodes, attribute uses or facts are manufactured.

Namespace declarations and admitted schema-location hints retain existing treatment without source acquisition. XML/XSI requests retain their established validation/refusal rules. This scope does not expand no-default-schema, active empty-group, all/choice, simple-content, mixed/assertion, wildcard or legacy routes. Missing default/fixed-valued attributes still require augmentation and remain Unsupported.

Complete Invalid/Unsupported assessment precedes facts. Positive empty owners retain original type/declaration handles and no projected group attributes. Recovery, cancellation, foreign ownership, detached child values, expiry and original XML/export retain their contracts. All source/type/attribute/depth/string/schema/regex/atom/value/lifetime limits remain.

The 96 authored contracts run through both public facades; nine native proofs verify original authority, alias/reference propagation, no-facts failure and lifetime behavior. Original upstream cases are rerun unchanged and reported separately. Package checks overlap source; no public API/Core pin or publication change is made.
