# ADR032: Strict attribute wildcards on sequence owners

Status: qualified source candidate,26November2026.

Carry immutable wildcard metadata through finite sequence plans and shared named-root aliases; keep original governing type/declaration components unchanged. Reuse strict attribute matching and preserve independent child validation and element-only no-typed-value behavior. Retain legacy grammar and resource/lifetime boundaries. [Adoption and qualification](sequence-wildcards/README.md). Core pin and exported API unchanged.
