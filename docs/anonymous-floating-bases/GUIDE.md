# Anonymous floating restriction bases

Both owned native facades admit a simple-type restriction whose one leading inline simpleType compiles to float or double. Dispatch uses the actual NativeType and retains it as the original unnamed direct DerivationBase. The existing floating compiler processes original facet elements, skipping only the exact inline base object. No alias, synthetic QName, declaration, global anonymous entry, source clone or namespace mutation is created. References share one base; independent definitions remain distinct. Named forward/final checks retain source authority.

Existing IEEE32/64 parsing, family-specific rounding, overflow/underflow, NaN and infinities remain. float maps 16777217 to 16777216; double maps 9007199254740993 to 9007199254740992. These are value mappings before facets, without a decimal intermediary. Native and detached values retain float/double family identity, including signed-zero bits. Schema enumeration treats the two zeros as equal and retains existing NaN equality. Transport does not erase a negative zero. No canonical NaN payload-bit promise is added.

Inherited enumeration, bounds, fixed values, whitespace collapse and lexical patterns retain their rules. Same-step pattern alternatives and inherited intersections remain. NaN bound endpoints and enumeration/bounds over patterned ancestors remain Unsupported. Finite/infinite bound checks reject NaN instances. Equal exclusive endpoints retain a legal empty value space; existing mixed-endpoint and fixed/inapplicable syntax classifications remain. No primitive lexical, conversion, equality, ordering or facet semantics change.

Shared inline source sites remain 16 and depth remains 4. Existing raw lexical256 and caller string/regex/schema/atom/value and lifetime limits remain. Complete assessment precedes facts. Original declarations, nil, XML, cancellation, foreign ownership, recovery, export, detached values and expiry retain their contracts. Broader simple-type/complex-content derivation, instance overrides and assertions require separate adoption. Source qualification does not establish full XSD 1.1, PSVI or public Core acceptance.
