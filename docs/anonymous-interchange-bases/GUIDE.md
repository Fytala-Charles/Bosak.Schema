# Anonymous binary and QName restriction bases

Both owned native facades admit a simple-type restriction whose one leading inline simpleType compiles to hexBinary, base64Binary or QName. Dispatch uses the actual NativeType object and retains it as the original unnamed direct DerivationBase. The existing interchange compiler processes original facet elements, skipping only the exact inline base object. No alias, synthetic QName, declaration, global anonymous entry, source clone or namespace mutation is created. References share one base; independent definitions remain distinct. Named forward/final checks retain source authority.

Binary values retain exact octets. Length facets count octets, and detached values retain their existing family kind and binary bytes. Hexadecimal case aliases and legal base64 whitespace map to equal values. Invalid base64 padding and nonzero unused pad bits remain Invalid. Canonical native binary text remains tagged with its existing schema family; no new binary XDM representation is introduced.

QName equality compares namespace URI and local name, independently of prefix. Facet literals resolve against the original facet element and its inherited namespace bindings; instance literals independently use original instance scope. An inner facet binding can differ from an outer binding with the same prefix. No namespace bindings are copied or rewritten. Detached QName values retain their existing namespace/local-name representation; native XDM QName payloads and original governing/actual type evidence remain.

Same-step pattern alternatives and inherited intersections remain. Enumeration over patterned ancestors stays Unsupported because lexical mapping affects membership. QName length facets, assertions, bounds and fixed pattern/enumeration syntax remain Unsupported. Binary length narrowing/fixed constraints and fixed whitespace collapse retain their existing classifications. No primitive grammar, equality, normalization or facet semantics change.

Shared inline source sites remain 16 and depth remains 4. Existing raw lexical256, binary128 octets, string/regex/schema/atom/value and lifetime limits remain. Complete assessment precedes facts. Original declarations, nil, XML, cancellation, foreign ownership, recovery, export, detached values and expiry retain their contracts. URI, other text and complex anonymous bases, wider derivation/instance overrides and assertions require separate adoption. Source qualification does not establish full XSD 1.1, PSVI or public Core acceptance.
