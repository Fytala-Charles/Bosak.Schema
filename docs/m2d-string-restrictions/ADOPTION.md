Supported facets: length, minLength, maxLength each at most once; enumeration may repeat, including duplicate values, combining by value-space union. Length values are nonNegativeInteger lexical forms after XML-whitespace collapse, including +0/-0/leadingzero spellings; require ASCII digits, raw256UTF16lexical ceiling and value0..65536. Numeric lexical errors/negative values and inconsistent direct minLength>maxLength refuse compilation as Unsupported/ValueType; capacity overflow is RepresentationCapacity. Duplicate singleton facets refuse DeclarationShape. Direct restriction of primitive string cannot combine length with minLength or maxLength: Datatypes4.3.1.4 permits that coexistence only when the bound is inherited from an earlier restriction without length; chains are excluded here. Such combinations refuse ValueType even if numerically consistent. No guessed grapheme/.NET code-unit length or .NET regex fallback.

Instance length counts Unicode scalar values (XML characters), including one per supplementary code point and two for e+combining acute. It is distinct from MaxStringCharacters, which bounds parsed UTF16code units before facet checks. XML1.0 parsing/line endings/character references are applied first; inherited xs:string whitespace preserve and exact sequence remain. No Unicode normalization, trimming, whitespace collapse, culture or case folding for enumeration. Compare enumeration values by exact ordinal equality of valid parsed strings. Literal attribute whitespace is normalized by XML before facet interpretation; referenced tab/CR/LF retain their parsed values. Enumeration is matched against any supplied value; duplicate spelling does not create an error. Facets intersect; do not reject an enumeration entry merely because it fails a different facet in the same direct restriction: it need only belong to base xs:string (4.3.5.5), and such an entry cannot make an instance pass the other facets.

Each enumeration facet parsed string is bounded by MaxStringCharacters before storage (RepresentationCapacity); at most16supplied enumeration entries per named type, duplicates included. All facet attributes except value, facet child/annotation elements and other facet kinds refuse under existing Attributes/DeclarationShape/ValueType rules.
