# ADR028: known-declaration anyType lax matches

Accepted for development0.20,26November2026.

The [pre-implementation contract](known-lax/CONTRACT.json) identifies the provenance boundary: current facts index a real governing declaration in the owned component ring. Adopt the exact REC revisions/sections in [ADOPTION](known-lax/ADOPTION.json) and qualify the known-declaration subset first. Resolve expanded names against closed global catalogs; validate actual plans/types and reuse original declaration handles. Do not create per-match declarations or normalize parent mixed text from child typed values.

Unknown lax content remains Unsupported rather than acquiring fabricated validation authority. Global attribute declarations do not imply required uses or absent-value augmentation. Retain source-order projection separately from hashed lookup, and preflight actual document node/depth/attribute bounds before recursion; enforce value-state count before ID checks and fact publication. Preserve cancellation, original XML, authority and expiry. Public API/Core pin and legacy grammar remain unchanged. See [guide](known-lax/GUIDE.md) and [qualification](known-lax/QUALIFICATION.json).
