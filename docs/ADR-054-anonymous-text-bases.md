# ADR054: Original anonymous URI and text-derived bases

Status: qualified source candidate, 28 November 2026.

Admit actual URI/text-derived NativeType bases through the original unnamed direct base route. Reuse the existing text facet compiler on original source elements, skipping only the exact inline child. Preserve URI flag, lexical family and normalization, Unicode scalar lengths, fixed/facet/pattern ancestry, identity checks, exclusions and limits without aliases or source clones. [Scope and qualification](anonymous-text-bases/README.md). API and Core pin unchanged.
