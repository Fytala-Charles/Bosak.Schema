# ADR034: Strict attribute wildcards on mixed sequences

Status: qualified source candidate,26November2026.

Reuse existing strict matching and mixed collectors while admitting their combination on finite nonempty explicit sequences. Keep actual governing components and untypedAtomic aggregate evidence separate, preserve raw descendant text rather than normalized child/attribute data, and retain all prior value/lifetime bounds. [Adoption and qualification](mixed-wildcards/README.md). API and Core pin unchanged.
