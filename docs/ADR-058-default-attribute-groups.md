# ADR058: Bounded schema default-attribute groups

Status: qualified source candidate, 28 November 2026.

Resolve the schema-level QName in its original scope and apply the actual cached group uses independently to supported source complex owners. Preserve set identity, duplicate conflicts, required/provided-value behavior and effective/aggregate limits without synthetic source nodes or instance augmentation. Keep the explicit owner/composition exclusions and zero-use extra-attribute refusal. [Scope and qualification](default-attribute-groups/README.md). No API/Core pin/publication change.
