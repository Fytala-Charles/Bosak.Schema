25 November 2026; batch slice15. Record exact verified slice14 main revision and immutable Structures REC20120405 sections4.2.4/3.17/3.16, Datatypes REC20120405 adopted restriction families and XDM31 REC20170321 before implementation.

Extend the existing catalog overloads, with no further public API rows, to import named simple-type libraries across namespaces. Foreign documents may contain only admitted named simpleType definitions and transitive closed include/import directives. Imported global elements, complex types, model/attribute groups and global attributes remain Unsupported: these need a later per-source owner/context compiler. Root-namespace components retain existing grammar and include behavior. Imported named simple restriction chains, including forward/cross-library bases, use actual source QName bindings, actual defining targetNamespace and genuine derivation-base components. Do not fake imports by renaming declarations or assigning all types the root namespace.

Introduce private immutable compiled-input namespace metadata keyed to each projected source component. Only catalog assembly creates this metadata; single-string XML cannot supply authority annotations. Carry it through both existing owned core factories into compilation. Existing simple-type duplicate checks and definition keys use actual expanded names; root anonymous/complex components retain root context. Same local type names in different namespaces are distinct; duplicate definitions within one namespace retain prior bounded refusal. Named type lookup and original native facts must report correct foreign component/base identities, not lexical aliases.

Import namespace must be a nonempty absolute URI distinct from the importing source namespace and must match the supplied imported source targetNamespace. Importing the importing source namespace or a mismatching imported namespace is Invalid. Missing schemaLocation, absent namespace/no-namespace import, unavailable catalog documents, unsupported URI profile, extra metadata/annotations or external composition return Unsupported. URI identifiers remain closed: no host network/file/DTD lookup. Includes in foreign libraries retain their actual library namespace; chameleon conversion remains Unsupported. URI deduplication validates each reference's expected namespace even when the document was previously visited. Import/include cycles and shared diamonds deduplicate safely; component graph cycles retain existing type restrictions/refusals.

Keep catalog8, each32KiB,total64KiB,identifier1024,aggregate32KiB and all current type/component/scalar/assessment bounds. Foreign simple-type-only documents may have different form/assertion defaults because these excluded owner/assertion constructs do not consume those defaults; preserve root include context comparisons. Reject non-simple components before compiling the library. Never expose invented source-URI provenance or mutate caller inputs.
