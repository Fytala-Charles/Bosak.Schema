# ADR061: Default groups on existing noninteger simple-content extensions

Status: qualified source candidate, 28 November 2026.

Reuse already-compiled noninteger source simple-content extension plans and original default-group/set identities. Preserve complex G/actual A/member authority and existing value/use/source/lifetime limits. Retain integer/Boolean, broader derivation, active wildcard/assertion, separate opt-out and augmentation boundaries. [Scope and qualification](simple-content-default-groups/README.md). No public API/Core pin or publication change.
