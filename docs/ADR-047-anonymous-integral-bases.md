# ADR047: Original anonymous integer and Boolean bases

Status: qualified source candidate, 27 November 2026.

Dispatch on actual compiled integer-family or Boolean NativeType bases. Keep direct unnamed base links and original facet sources without aliases, synthetic QNames or source cloning. Preserve integer exact facets/numeric patterns, Boolean fixed collapse/pattern ancestry, existing exclusions and finite budgets. [Scope and qualification](anonymous-integral-bases/README.md). API and Core pin unchanged.
