# Bosak.Schema Roadmap

> An open schema foundation with staged validation and integration.


## 1. Current Milestone

The 0.4 development line makes schema services Apache-2.0 and activation-free. Public source contains the schema implementation/tests only; the original commercial infrastructure and full Git history remain private. No NuGet release/tag is included in this migration.

## 2. Next Milestones

1. Reassess the smallest useful core/session API now that licensing no longer dictates a proprietary plug-in boundary.
2. Qualify complete component/universe identity, compatible-schema handoff, PSVI/atomic flow and bounded resource ownership.
3. Implement or explicitly refuse remaining XSD 1.1 structural/assessment coverage.
4. Build/test real consumers and unchanged binaries, then run the full engine/conformance gates before API freeze or release.

## 3. Validation and Limits

The public schema suite passes 124 cases. Existing core package pins stay at 1.26.3. Neither current-draft XDM certification nor full XSD 1.1 support follows from the Apache transition. Billing/key-generation, other product licensing, Folio, XmlDb storage and Braid workflows remain outside this source change.
